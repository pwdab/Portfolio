# 1. 👋 Introduction

Unreal Engine 5를 주로 다루는 **C++ 게임 클라이언트 프로그래머**입니다.  

**Replication/RPC**를 활용한 네트워크 동기화, **AnimBP** 기반 애니메이션 제어, **Online Subsystem**을 통한 세션 관리 경험을 보유하고 있습니다.  

세션 잔존, 닉네임 인코딩 깨짐, 시선 Rotator 불일치 등 다양한 **실전 이슈**를 해결하며 **안정적인 게임플레이 환경**을 구현했습니다.  

이러한 경험을 바탕으로 개발한 프로젝트를 Steam에 게시해 **2,000회 이상의 다운로드**를 기록했습니다.  

최근에는 개인 프로젝트를 통해 구현을 넘어 **설계와 모듈화**의 중요성을 깨닫고 있으며, 모던 C++ 학습을 통해 구조적 사고를 더욱 확장해 나가고 있습니다.  

앞으로도 꾸준히 배우고 성장하여, 더 많은 플레이어들에게 **안정적이고 즐거운 게임 경험**을 선사하는 클라이언트 프로그래머로 나아가겠습니다.

## 🛠 이슈 및 해결 과정   
### 캐릭터 시선 Rotator 불일치
- **문제**: 호스트 캐릭터는 시선 Rotator에 따라 정상 회전하지만 로컬 캐릭터는 Rotator가 초기값으로 돌아감  
- **원인**: `AnimInstance::NativeUpdateAnimation()`에서 Rotator를 직접 계산 및 적용해 네트워크 상에 동기화되지 않음  
- **해결**: 로컬 변경값을 서버 RPC로 전달하고 서버가 NetMulticast로 모든 클라이언트에 전파  
- **결과**: 모든 클라이언트에서 동일한 시선 처리가 가능해져 조작감이 개선됨

### 클라이언트 세션이 초기화되지 않는 현상
- **문제**: 호스트 종료 후 클라이언트가 이미 종료된 세션에 접근해 Find Session 목록 갱신 불가  
- **원인**: 호스트가 먼저 세션을 종료해 클라이언트에서 존재하지 않는 세션에 접근
- **해결**: 호스트 종료 전 RPC로 클라이언트에게 세션 종료를 요청해 각 클라이언트가 세션 종료 후 호스트 세션 종료  
- **결과**: 모든 클라이언트 세션이 정상적으로 종료되어 세션 목록이 항상 최신 상태를 유지  

### Steam 닉네임이 비정상적으로 출력
- **문제**: Find Session 결과에서 Steam 닉네임이 깨져 표시됨  
- **원인**: Online Subsystem의 ASCII 직렬화 과정에서 손실 발생
- **해결**: 세션 생성 시 UTF-16 → UTF-8 → Base64 인코딩 후 전송 및 수신 측에서 Base64 → UTF-8 → UTF-16으로 복원  
- **결과**: 한글 포함 모든 닉네임이 정상 출력
